# Agent 平台改造实录 —— 一个生产型 Agent Harness 的改造手记（对外技术博客系列）

计划 8 篇。前 4 篇已有提纲，约 3.6 万字（含 5 张 Mermaid 图源码）。全部基于真实项目复盘，已按 `../share/00-writing-rules.md` 的三层脱敏规则处理（系统名/工具名/业务场景抽象、数值区间化、技术指标保留）。

**定位**：深入解析 Agent 生产过程中的核心 Harness 工程——agent 循环、工具调用协议、上下文与能力供给、沙箱执行、状态恢复。写夹具层怎样上线、运维、长大。和「Agent 从 0 到 1」入门手记分开：那一组用故障现场把要补的东西讲清楚，这一组把实现拆开。

**建议标签**：`Agent Harness` · `Agent Infrastructure` · `LLM Runtime` · `Context Engineering`

## 每篇的固定结构

1. 引子（一个真实数字对比或事故现场）
2. 第一性主线（从物理/协议约束推演方案，含弯路与被回滚的重构）
3. 深潜走读（一次真实调用/事故的逐站/逐秒还原）
4. 代价与未解决的问题（诚实清单，非编造）
5. 收束（可迁移原则 + 篇间交接）
