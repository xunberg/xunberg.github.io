**定位**：模型外围运行时层——Agent Harness（agent 循环、工具调用协议、上下文与能力供给、沙箱执行、状态恢复）——的生产化工程。这里的题目不是让模型变强，而是让夹具层能上线、能运维、能长大。

## 与 share/ 系列的区分

| | `../share/`（Agent 生产化手记，8 篇） | `blog/`（本系列，8 篇） |
| --- | --- | --- |
| 定位 | 方法论科普，观点驱动 | 工程深潜，第一性原理推导 |
| 单篇体量 | 约 2000–2800 字（5–7 分钟） | 约 7700–12000 字（19–30 分钟） |
| 读者 | 产品/泛技术读者 | 后端/平台/Agent 工程师 |
| 内容颗粒 | 原则 + 少量案例 | 完整演进史 + 深潜走读 + 代价清单 |
| 结构 | 叙事短文 | 引子 → 第一性主线 → 深潜走读 → 代价与未解决 → 收束原则 |

同一素材两套写法，可先后发布互不冲突（share 打认知，blog 收工程师读者）。

## 每篇的固定结构

1. 引子（一个真实数字对比或事故现场）
2. 第一性主线（从物理/协议约束推演方案，含弯路与被回滚的重构）
3. 深潜走读（一次真实调用/事故的逐站/逐秒还原）
4. 代价与未解决的问题（诚实清单，非编造）
5. 收束（可迁移原则 + 篇间交接）
